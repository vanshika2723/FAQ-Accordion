# FAQ Accordion

A modern and responsive FAQ Accordion built using HTML, CSS, and JavaScript.

## 📌 Project Overview

The FAQ Accordion is an interactive web component that allows users to view frequently asked questions and their answers by clicking on each question.

The project focuses on creating a clean user interface with smooth accordion animations and responsive design.

## 🌐 Live Demo

🔗 **Live Website:**https://vanshika2723.github.io/FAQ-Accordion/

## ✨ Features

- 8 Frequently Asked Questions
- Expand and collapse FAQ answers
- Only one FAQ opens at a time
- Interactive plus icon animation
- Smooth transitions
- Modern and clean UI
- Fully responsive design
- Mobile-friendly layout
- Built with vanilla JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
